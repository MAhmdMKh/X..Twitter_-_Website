--(-- Specificity of CSS Selectors & their Priority --)--

I finished my HTML & CSS course, but the real learning started when I began building projects.

I quickly ran into styling and had to know about CSS Specificity. Here is the priority scoring system everyone needs to know:

1️⃣ Inline styles = 4 pts
2️⃣ IDs ( #id ) = 3 pts
3️⃣ Classes ( .class ) = 2 pts
4️⃣ Elements ( div ) = 1 pts

If your CSS isn't applying, check your scores! Highest points win.

What tripped you up most when you started building? Let's have fun in the comments.👇
